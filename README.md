## Установка зависимостей

```bash

```

```bash

```

```bash
uv run pre-commit install
uv run pre-commit run --all-files
```

## Очистка

(Остановить контейнеры, сохранив данные Kafka: ...)

```bash

```

Удалить контейнеры и все Kafka volumes:

```bash
docker compose down -v
```

Команда `down -v` удаляет сохранённые сообщения и offsets учебного кластера.
